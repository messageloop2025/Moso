## 1. 基础与权限

| 编号 | 功能项 | 描述 | 优先级 |
|------|--------|------|--------|
| F1.1 | 数据库 | 使用 SQLite 存储全部业务数据 | P0 |
| F1.2 | 用户系统 | 支持管理员/普通用户，登录、注册、权限区分 | P0 |
| F1.4 | 登录/注册验证码 | 登录与注册时需完成简单数学验证码（a+b=?），答案随 token 提交校验，防暴力尝试 | P0 |
| F1.3 | 操作日志 | 系统所有关键操作均记录日志（谁、何时、操作类型、参数、结果等） | P0 |
| F1.5 | 修改密码 | 当前用户自助修改密码（POST /auth/change-password）；管理员可为任意用户重置密码（POST /users/{id}/reset-password） | P0 |
| F1.6 | 每用户数据隔离 | 操作日志：普通用户仅能查看自己的日志，管理员可查看全部并按 user_id 筛选；本地文件系统根目录为 web/fs/当前用户名，普通用户仅能访问自己的目录，管理员可通过参数访问指定用户目录；AI 模型配置为每用户独立（`user_ai_model_profiles` + 激活项），每人可维护多组 Key/URL/模型 | P0 |
| F1.7 | 账户删除 / 自助注销（彻底级联清理） | 管理员删除用户（`DELETE /users/{id}`）或用户自助注销（`POST /users/me/delete`，需输入密码 + 二次确认 `DELETE`）时，**一次性清理与该用户相关的所有数据**：该用户所建主机 + 这些主机在**被分享用户**侧产生的所有每用户数据（聊天会话与消息、主机知识、主机提示词、标签、SSH 通道、批量明细、操作日志）+ 分享关系；以及该用户自身的 AI 会话、个人 AI 配置、系统共享 Key 调用计数、个人 SMTP、API 令牌、触发/定时任务及其 runs/messages/expose、批量操作、本机 Shell、登录事件、维护历史、凭证、主机分组 等；`best_practices` 仅移除归属。管理员禁止自助注销以避免最后一位管理员被删除；`web/fs/<username>/` 工作目录同步清除。实现见 `api/users.py::delete_user_with_cascade` | P0 |
