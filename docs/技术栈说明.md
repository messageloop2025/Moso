# 毛竹 技术栈说明

## 1. 总体选型

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | 原生 HTML/CSS/JavaScript（无框架） | 单页应用，深色科技风 UI，参考 IOTHub；便于与后端 API、WebSocket 对接 |
| 后端 | Python 3.10+ / FastAPI | 异步、自动 OpenAPI、依赖注入、与 Paramiko 等库配合方便 |
| 数据库 | SQLite | 设计文档要求；单文件、零配置，适合中小规模部署 |
| SSH/SCP | Paramiko | Python 生态常用 SSH2 库，支持密码与密钥认证、命令执行、SFTP/SCP |
| 认证 | JWT (python-jose) + bcrypt | 无状态登录；密码哈希存储 |
| AI | 兼容 OpenAI API 的 HTTP 接口 | 可配置 base_url、model，用于对话与后续 Agent/Skills 调用 |

## 2. 后端依赖（requirements.txt 核心）

- **fastapi**：Web 框架  
- **uvicorn[standard]**：ASGI 服务器  
- **aiosqlite**：异步 SQLite 驱动  
- **python-jose[cryptography]**：JWT 编解码  
- **bcrypt**：密码哈希  
- **pydantic / pydantic-settings**：请求/配置校验  
- **paramiko**：SSH/SCP  
- **httpx**：异步 HTTP 客户端（调用 LLM、可选）  
- **PyYAML**：AI 通用数据处理工具 `data_query` 解析 YAML / YML  
- **BeautifulSoup4**：AI 通用数据处理工具 `markup_query` 解析与搜索 HTML/XML  
- **python-multipart**：表单/文件上传（聊天附件、SCP 上传界面等）
- **markitdown[pdf,docx,pptx,xlsx]**：聊天附件中 Office/PDF 等富文档转为 Markdown（`services/markitdown_convert.py`）；Docker 镜像另需系统包 `libmagic1`
- **mcp**：毛竹 内置 MCP（`services/edgeops_mcp`），默认随主 Web 同端口挂载 `/mcp`，**47** 个 `edgeops_*` 工具（含 claw-ops 同名 22 个 + 编排/ssh_execute 等扩展）

## 3. 前端资源

- **无构建工具**：直接引用 JS/CSS，部署简单。  
- **样式**：`web/css/style.css`（深色主题、侧栏、卡片、表格、模态框、Toast、运行中控制条、聊天排版、公式与代码高亮等）；`web/css/xterm.min.css` 为终端样式。  
- **终端**：xterm.js（`web/js/xterm.min.js`）+ FitAddon（`web/js/addon-fit.min.js`，@xterm/addon-fit 本地副本），用于 SSH 终端填满容器；WebSocket 使用浏览器原生 API。  
- **聊天渲染**：`web/js/utils.js` 内置 Markdown 渲染、空行压缩、安全 HTML 标签归一化、代码高亮、diff/log/tree/http 块、Callout、Mermaid/Markmap/ECharts 占位增强，以及 LaTeX 公式本地 fallback（sqrt、frac、上下标、mathbf、mathrm、text 等）。流式 SSE 回复使用 `edgeopsRenderStreamIncremental`：闭合块（代码围栏、完整表格、段落）即时渲染并冻结，尾部未完成内容纯文本/增量表格，结束后完整排版收尾。  
- **资源本地化**：所有前端资源均放在 `web/` 下，通过 `/static/` 提供，不依赖任何 CDN 或外链；聊天代码高亮与公式渲染也不依赖外部 CDN；详见 `web/README.md`。

## 4. 运行环境

- **Python**：3.10 及以上（推荐 3.11+）  
- **操作系统**：Windows / Linux / macOS（Paramiko 与 SQLite 跨平台）  
- **浏览器**：支持 ES5+、Fetch、可选 WebSocket 的现代浏览器

## 5. 配置与环境变量

- **EDGEOPS_DB**：SQLite 数据库文件路径，默认 `edgeops.db`  
- **EDGEOPS_SECRET**：JWT 签名密钥  
- **EDGEOPS_HOST** / **EDGEOPS_PORT**：服务监听地址与端口，默认 `0.0.0.0:8010`  
- **EDGEOPS_VERSION**：版本号（可选）  
- **EDGEOPS_WORKERS**：多进程 worker 数；**默认 0 = 单进程（推荐）**；内置定时任务调度器每个进程各跑一份，多 worker 可能重复触发；SQLite 写并发也有限。**非必须请勿设 ≥1**。Windows 下即使用环境变量也会强制单进程。  
- **EDGEOPS_SQLITE_BUSY_TIMEOUT_MS** / **EDGEOPS_SQLITE_WAL**：SQLite 多人并发时的锁等待与 WAL 模式（默认开启），详见 [并发与扩展.md](并发与扩展.md)。  
- **FS_DIR**：本地文件系统存储根目录（默认 `web/fs`）；运行时按用户名建子目录，每用户仅能访问自己的目录  
- **AI_API_KEY** / **AI_BASE_URL** / **AI_MODEL**：全局 AI 默认（可被每用户配置覆盖）；未配置个人 KEY 的用户自动使用系统 KEY，调用次数按用户计入 user_system_ai_usage 表  
- **EDGEOPS_SYSTEM_AI_USAGE_LIMIT**：仅当用户未配置自己的 KEY 而使用系统 KEY 时的每用户调用次数上限，**默认 2000**；用户配置了自己的 KEY 则不受此限制（解锁无限调用）；达上限后 `/api/ai/chat` 不再 403 而是流式返回固定文案，一次性 summarize 端点仍返回 403；管理员可通过 AI 技能 `reset_user_system_ai_usage` 重置某用户次数  
- **EDGEOPS_AGENT_MAX_STEPS** / **EDGEOPS_ASSISTANT_MAX_ROUNDS**：AI 步数/辅助轮数（可选）。会话级 `low_interaction_mode` 会影响辅助 AI 是否频繁询问继续；低交互模式仍会在轮次耗尽、执行失败或缺必要条件时停下反馈。  
- **EDGEOPS_AI_CONTEXT_SIZE** / 设置项 **ai_context_size**：聊天上下文总字符数上限（0 表示不限制，支持到 8MB）；超出时按比例分段截断。前端下拉可选到 8M，并支持手工输入；`config.CONTEXT_SIZE_OPTIONS`、`CONTEXT_SIZE_MAX` 控制选项与上限
- **EDGEOPS_MARKITDOWN_ENABLED** / **EDGEOPS_MARKITDOWN_MAX_OUTPUT_CHARS**：聊天附件 Office/PDF→Markdown（默认开启；单次转换字符上限默认 50 万）
- **EDGEOPS_CHAT_ATTACHMENT_MAX_BYTES** / **EDGEOPS_CHAT_ATTACHMENT_SESSION_QUOTA_BYTES**：单附件与单会话附件总大小软限（默认 20 MB / 500 MB）
- **EDGEOPS_MCP_ENABLED**：是否在主 Web 同进程挂载 MCP HTTP（默认 `true`；设 `false` 关闭）
- **EDGEOPS_MCP_HTTP_PATH**：MCP 挂载路径（默认 `/mcp`，与 `EDGEOPS_PORT` 同端口）
- **EDGEOPS_MCP_HOST** / **EDGEOPS_MCP_PORT**：仅独立 `python -m services.edgeops_mcp --http` 时监听（默认 `127.0.0.1:8011`）
- **EDGEOPS_MCP_API_BASE_URL**：MCP 工具回连 毛竹 REST 根 URL；省略时按本机 `HOST:PORT` 推断
- **EDGEOPS_MCP_ACCESS_TOKEN** / **EDGEOPS_ACCESS_TOKEN**：MCP stdio 或 fallback Bearer；HTTP MCP 优先用客户端请求头
- MCP 回连 REST 时自动带 **`X-EdgeOps-Client: mcp`**（`/api/integration/mcp/*` 专用接口校验）
- **EDGEOPS_HTTP_TOOL_ENABLED**：AI HTTP 出站工具总开关（默认 `true`）
- **EDGEOPS_HTTP_TOOL_ALLOW_INSECURE**：是否允许 `http://` 明文（默认 `false`）
- **EDGEOPS_HTTP_TOOL_SSRF_BLOCK_PRIVATE**：禁止访问内网/本机/元数据地址（默认 `true`）
- **EDGEOPS_HTTP_TOOL_MAX_RESPONSE_BYTES** / **EDGEOPS_HTTP_TOOL_MAX_DOWNLOAD_BYTES** / **EDGEOPS_HTTP_TOOL_MAX_UPLOAD_BYTES**：响应/下载/上传字节上限（**下载/上传默认 0=不限制**）
- **EDGEOPS_HTTP_TOOL_DOWNLOAD_CHUNK_SIZE**：分块下载默认块大小（默认 64MB）
- **EDGEOPS_HTTP_TOOL_DEFAULT_TIMEOUT_SEC** / **EDGEOPS_HTTP_TOOL_MAX_TIMEOUT_SEC**：HTTP 工具超时（默认 60s / 3600s）
- **EDGEOPS_TRUST_PROXY_HEADERS** / **EDGEOPS_TRUSTED_PROXY_HOSTS**：反代后保留 HTTPS（默认 trust=true；hosts=`*`）

## 6. 外部智能体集成

| 组件 | 路径 | 说明 |
|------|------|------|
| claw-ops | `claw-ops/` | OpenClaw Node 插件，**22 核心 + manifest 动态扩展**（v1.1+；baseline 43 工具） |
| claw-skills | `claw-skills/` | Hermes 技能（REST + Token 配置 + MCP 说明） |
| edgeops_mcp | `services/edgeops_mcp/` | Python FastMCP，**52** 工具；默认 `/<port>/mcp`；编排 ops **仅 MCP** |
| user_mcp_* | `services/user_mcp_*.py`、`api/user_mcp_servers.py` | 每用户第三方 MCP 配置；网页 `/mcp-servers`；导入/导出 |
| user_skills_* | `services/user_skills_{registry,runtime,export,hooks}.py`、`api/user_skills.py` | 每用户 Agent Skills（Cursor 格式、渐进式披露、斜杠 Command/`commands/`/`{{arg}}`、hooks.json 与 matcher 决策、导入导出）；须 `skills_enabled` |
| chat_mode_* | `services/chat_mode_gate.py`、`chat_mode_runtime.py`、`chat_mode_enforce.py` | 会话聊天模式（qa/strict/normal）硬门禁；严格独立确认模态与「总是」按工具名会话缓存；`user_decision` 回写；审计 |

鉴权统一为 **`Authorization: Bearer`**（JWT 或 `eop_` API Token）。详见 [外部集成与ClawOps.md](外部集成与ClawOps.md)。

## 7. 启动方式

- **命令行**：`python app.py` 或 `uvicorn`；Windows 可使用项目根目录下 **start.bat** 启动（自动切到脚本目录、可选激活 venv、默认端口 8010）。  
- **Docker**：在项目根目录执行 `docker compose -f docker/docker-compose.yml up -d`，代码与数据库通过卷映射挂载、不放入镜像；详见 [Docker部署.md](Docker部署.md)。反代示例见 [docker/nginx-edgeops.example.conf](../docker/nginx-edgeops.example.conf)（HTTPS + `/mcp` 不降级）。  
- **浏览器**：访问 `http://localhost:8010`（或配置的端口）。  
- **MCP（默认开启）**：Cursor 等客户端连接 `http://localhost:8010/mcp`（与 Web 同端口）；关闭设 `EDGEOPS_MCP_ENABLED=false`。
