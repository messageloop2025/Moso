# 本机管理步骤手册（仅管理员）

本机管理用于操作 **运行 毛竹 的这台机器本身**，而不是远程 SSH 主机。它适合做平台维护、部署、日志检查、文件处理、进程控制等管理员级任务。

因为作用范围更大，所以风险也更高。推荐先理解边界，再执行操作。

---

## 1. 什么时候该用本机管理

适合场景：

- 查看 毛竹 本机日志
- 修改本机配置文件
- 管理部署目录
- 启动、停止、查看本机进程
- 读写本机文件
- 调试本机脚本

不适合场景：

- 管理远程服务器
- 存放普通用户自己的脚本工作区
- 替代 `web/fs` 做常规材料管理

如果目标是远程 Linux / Windows / ESXi 主机，请回到主机管理、AI 助手或批量任务。

---

## 2. 先理解它和 `web/fs` 的区别

| 能力 | `web/fs` | 本机管理 |
|------|----------|----------|
| 范围 | 用户自己的工作区 | 毛竹 所在机器 |
| 路径 | 相对路径 | 绝对路径或项目根相关路径 |
| 用途 | 脚本、模板、上传材料 | 本机运维、日志、部署、进程 |

### 记忆方法

- `web/fs`：更像“每个用户的运维工作区”
- 本机管理：更像“服务器管理员控制台”

所以：

- 用户准备部署材料，用 `web/fs`
- 管理员改 毛竹 本机环境，用本机管理

---

## 3. 推荐的使用顺序

做本机操作时，建议顺序是：

1. 先明确目标路径或目标进程
2. 先读再写
3. 先小范围操作
4. 高风险前先备份
5. 执行后立刻验证

这条顺序尤其适用于：

- 改配置文件
- 删文件
- 终止进程
- 写二进制文件

---

## 4. 在本机执行一条命令

### 适用场景

- 查看目录
- 检查服务状态
- 读取日志
- 查看环境变量
- 快速做一次本机排查

### 可用能力

- `local_exec`
- `local_run_script`

### 推荐步骤

1. 先确认命令是在本机执行，不是远程主机
2. 先执行只读命令
3. 检查输出
4. 确认结果后再执行修改类命令

### 示例

Windows：

```powershell
dir
tasklist
```

Linux：

```bash
pwd
ls -la
ps -ef
```

---

## 5. 运行本机脚本

`local_run_script` 适合做比单条命令更复杂的事情。

### 适合场景

- 执行 Python 脚本
- 做批量本机文件处理
- 调试本地接口
- 自动化整理部署目录

### 推荐步骤

1. 先明确脚本目标
2. 尽量先在小范围路径验证
3. 执行脚本
4. 检查输出与影响

### 建议

- 先做只读或模拟执行
- 涉及删除、覆盖、移动时先备份

---

## 6. 浏览和管理本机文件

本机文件系统能力适合处理 毛竹 所在机器的文件，而不是远程主机文件。

### 常见操作

- 列目录
- 读文本文件
- 写文本文件
- 建目录
- 删除文件
- 重命名或移动
- 截断文件
- 读写二进制文件

### 推荐步骤

1. 先 `list`
2. 再 `read`
3. 确认目标正确后再 `write` / `rename` / `delete`

### 为什么建议这样做

因为本机文件路径通常影响真实部署环境，误改代价比 `web/fs` 大得多。

---

## 7. Windows 与 Linux 下的路径理解

### Windows

- path 为空或 `/` 时，会看到驱动器列表，如 `C:`、`D:`
- 进入 `C:/` 后，看到该盘根目录内容

### Linux

- path 为空或 `/` 时，表示系统根目录
- 之后可继续进入 `/etc`、`/var/log`、`/opt` 等路径

### 建议

- 不确定路径时先列目录，不要直接写入
- 路径操作前先确认你当前是在 Windows 还是 Linux

---

## 8. 修改本机配置文件

这是高频但也高风险的操作。

### 适用场景

- 修改服务配置
- 改部署参数
- 调整日志配置
- 更新系统或应用配置文件

### 推荐步骤

1. 先读取原文件
2. 备份原文件
3. 再写入新内容
4. 保存后验证语法或服务状态

### 推荐习惯

- 先备份再改
- 每次只改一小段
- 改完立刻验证，不要堆积多个改动一起测

---

## 9. 删除、重命名、截断文件

这三类动作都具有较高风险。

### 删除前建议先确认

- 文件是否仍被服务使用
- 是否属于日志、配置、数据库或部署关键文件
- 是否可以先备份

### 重命名前建议先确认

- 是否有脚本或服务依赖原路径
- 是否会影响系统启动或应用运行

### 截断前建议先确认

- 是否真的只是清空日志
- 是否会误清业务数据

### 推荐原则

- 看不懂的文件先不要删
- 关键目录先不要直接批量处理
- 高价值文件先备份

---

## 10. 处理本机二进制文件

本机管理支持读写二进制内容，适用于：

- 处理压缩包
- 处理证书文件
- 处理图片、安装包或导出文件

### 建议

- 二进制文件操作前先确认类型和路径
- 大文件或关键文件不要轻易覆盖
- 不确定时先读、先备份、再写

---

## 11. 管理本机进程

进程管理适合查看、启动、等待、终止由系统托管的进程。

### 可做的事

- 启动一个进程
- 查看它是否还活着
- 读取 stdout / stderr
- 向 stdin 写入
- 等待结束
- 强制终止

### 典型流程

1. `process_start`
2. 观察 stdout / stderr
3. 如有需要写入 stdin
4. `process_wait`
5. 结束不了再 `process_terminate`

### 适合场景

- 跑一个本机脚本任务
- 启动需要持续观察输出的命令
- 做临时调试

---

## 12. 终止进程前要注意什么

终止进程是高风险动作。

### 先确认

- 这个进程是不是业务关键进程
- 有没有别的替代方式
- 停掉后会不会影响在线服务

### 推荐步骤

1. 先确认进程用途
2. 能优雅退出就先优雅退出
3. 仅在必要时强制终止

---

## 13. 使用本机终端（控制台）

本机管理页也有自己的本机终端，适合连续交互。

### 打开方式

- 用户点击 `+ 新建控制台`
- AI 调用 `create_local_console`

### 关闭方式

- 用户可点 `×`
- AI 可关闭自己创建的本机控制台

### 自动切换规则

- AI 向 AI 创建的本机终端执行操作时，可自动切换
- 用户若切到用户终端，自动切换会暂停

### 推荐用途

- 连续查看本机日志
- 连续执行多步命令
- 观察部署过程

---

## 14. 文件系统 Tab 怎么用

本机管理页里的文件系统 Tab，适合可视化地处理本机文件。

### 适合场景

- 浏览目录树
- 读写文本文件
- 上传或下载本机文件
- 改脚本、看 Markdown、改配置

### 推荐步骤

1. 先浏览到目标目录
2. 先预览文件
3. 再决定是否编辑或保存
4. 删除前再确认一次

## 15. 配置项说明

### `EDGEOPS_LOCAL_MANAGE_ROOT`

表示本机管理的根目录基准。未设置时通常使用项目根。

### `EDGEOPS_LOCAL_MANAGE_FULL_FS`

- `true`：允许访问更广的本机绝对路径
- `false`：限制在根目录范围内

### Windows `pywinpty`

在 Windows 上安装 `pywinpty` 后，可获得更完整的终端体验。

## 16. 常见问题

### 16.1 为什么本机管理里看不到我想要的路径

优先检查：

- 当前是否受根目录限制
- 路径是不是写错了
- 当前系统是 Windows 还是 Linux

### 16.2 为什么进程启动了但没输出

优先检查：

- 是否读取了 stdout / stderr
- 命令是否本身无输出
- 进程是否已经结束

### 16.3 为什么写文件后服务不正常

优先检查：

- 配置语法是否正确
- 路径是否写错
- 是否覆盖了错误文件
- 是否忘了重载或重启服务

---

## 17. 推荐的使用习惯

- 本机管理先读后写
- 修改前先备份
- 终止进程前先确认影响
- 删除文件前先确认用途
- 把 `web/fs` 和本机管理严格区分开
- 高风险动作尽量让 AI 先给计划再执行
