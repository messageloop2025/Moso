# 模型配置

侧栏 **「模型配置」**（`/model-config`）用于管理你的 AI 连接参数。自 v1.4.3 起，原「系统设置 → 我的 AI 配置」已迁移至此，并支持**多组命名配置**。

---

## 1. 基本概念

| 概念 | 说明 |
|------|------|
| **Profile（配置组）** | 一组完整的 AI 参数：名称、API Key、服务地址、模型、系统提示词等 |
| **当前使用（激活）** | 列表中标记为激活的一组；AI 助手、主机 AI、定时/触发任务均使用它 |
| **默认配置** | 升级后自动从旧单行配置迁移的首个 Profile 名 |

每用户最多 **20** 组；至少保留 **1** 组。

---

## 2. 常用操作

### 新建

1. 打开「模型配置」
2. 点击 **「新建配置」**
3. 填写名称与连接参数，保存

### 编辑 / 删除

- 列表行 **「编辑」**：修改该组全部字段（API Key 留空或 `***` 表示不修改原值）
- **「删除」**：删除非激活或多余配置；最后一组不可删

### 设为当前

- 列表 **「设为当前」**，或 AI 聊天栏 **「当前模型」** 下拉切换

### 导入 / 导出

- **导出全部** / 行内 **「导出」**：下载 JSON（含 api_key，请妥善保管）
- **导入**：粘贴 JSON，选择：
  - **保留现有，仅导入新增（同名跳过）**
  - **覆盖同名配置，并导入新增**

JSON 格式示例：

```json
{
  "_edgeops": {
    "version": 1,
    "type": "ai_model_profiles",
    "active_profile_name": "默认配置"
  },
  "profiles": [
    {
      "name": "默认配置",
      "api_key": "...",
      "base_url": "https://...",
      "model": "...",
      "provider": "aliyun",
      "auto_approve": false,
      "assistant_enabled": false,
      "context_size": 0,
      "vision_enabled": true,
      "output_locale": ""
    }
  ]
}
```

---

## 3. 字段说明

| 字段 | 说明 |
|------|------|
| 模型类型 | 阿里云 DashScope / Ollama / OpenAI；影响默认地址与请求格式 |
| 服务地址 | OpenAI 兼容 API 的 Base URL |
| API Key | 自有 Key；留空则使用系统共享 Key（有次数上限） |
| 模型 | 模型 ID / 名称 |
| 上下文长度 | 字符上限，0=不限制 |
| 系统提示词 | 覆盖内置主助手提示词（留空则用产品内置） |
| 自动审批 | 是否跳过部分 AI 动作确认 |
| 辅助 AI | 是否在每轮后由辅助模型判断是否继续 |
| 支持图像识别 | 是否将图片以多模态内联到消息 |
| 回复语言 | 空=跟随站点/浏览器；可选 en / zh-CN |

---

## 4. 系统共享 Key 与配额

- 仅当**未填自有 API Key** 且**未在 Profile 中指定自有 Base URL**（仍走全局/系统云 endpoint）时，才使用管理员配置的系统 Key 并计入配额
- **Ollama / 本地模型**：在 Profile 中填写 Base URL（如 `http://127.0.0.1:11434/v1` 或局域网 `:11434`），API Key 可留空；**不会**走系统共享 Key，也不计配额。模型类型建议选 **Ollama (local)** 或留空自动探测
- 默认每用户 **2000** 次（可配置）；**填写自有 Key** 或 **自有 Base URL（本地推理）** 后解除共享配额限制
- 「模型配置」页顶部显示配额；管理员可在「用户管理 → AI 配额」重置或写入系统默认配置

---

## 5. 与系统设置的区别

| 页面 | 内容 |
|------|------|
| **系统设置** | 显示语言、站点 SMTP 占位、搜索服务、API Token 等 |
| **模型配置** | AI Key、模型、提示词、Profile 管理 |

管理员的全局 AI 默认值仍在 settings / 环境变量中，用于共享 Key 与用户缺项补全。

## 6. 运行时模型身份（AI 自知）

后端在每轮 **AI 聊天 / 集成 API / 后台任务 / 子 AI / MCP 编排** 的 system prompt 中注入「当前运行时模型身份」块，内容包括：

- 激活 Profile 名称与 id
- 本轮请求的 **model id**、**provider**、**base_url**
- **上下文预算**（用户配置值或自动估算字符数）
- 识图开关、Agent 步数、API Key 来源（自有 / 系统共享配额）

用户问「你是什么模型」「上下文窗口多大」时，AI 会依据该块回答，无需用户手动告知。
